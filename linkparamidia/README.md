# Link para Mídia Android
Build branch only, isolated from Android DLSS main. Native Android application with audio/video downloading using youtubedl-android, MP3 or MP4 output, playlist support, SAF folder selection and interval clipping with strict post-download duration validation. Never claims success when no valid files exported. Dependencies GPL-3.0: review distributor obligations and attribution before external release.
## Build
Gradle 8.9 / JDK 17 / Android SDK 35. GitHub Actions workflow publishes an unsigned debug APK as artifact and attempts emulator install/start smoke test.
External media platforms may block or restrict downloads; no bypass or guaranteed universal access. For media you have rights to download and convert.
